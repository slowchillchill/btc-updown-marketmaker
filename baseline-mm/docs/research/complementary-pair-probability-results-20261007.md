# 十八日概率与Binance增量研究结果（UTC 2026-10-07）

本次完成了UTC 2026-09-09—09-23研究窗的四折前向验证，以及9—23日最终冻结后对24—26日开发窗的评价。一次prepare和一次study均成功。以下结论对应来源级概率统计，正式参数尚未采用，任务3的完整经营候选及公共回测仍待完成。

- **波动窗口：300秒。** 五次拟合均在15、30、60、120、300秒有限候选中选中300秒。
- **初始波动率：候选中的2倍拟合sigma。** 有实际fallback样本支持，不是精确并列时按候选顺序选择。但最后开发窗的fallback为0，不能据此证明生产冷启动最优。
- **epsilon：0倍。** 五次拟合均选择0；这是二元Brier下的误差尺度选择，不表示连续结算价格残差为零。
- **Binance修正：价格创新有一致的前向改善。** 权重0.5在四折和开发窗的各自共同交集均降低Brier。深度修正没有稳定改善；成交修正的变化为约10⁻⁸至10⁻¹⁰且方向不一致，没有稳定实质改善。

开发窗的基线Brier为**0.084219026**，创新修正为**0.082482107**，共同交集差值为**−0.001736919**。两者均评价6,041个样本。该概率改善不证明自身成交后的账户盈利。完整有限候选、冻结参数、全部十桶及必要分层见[紧凑机器证据](complementary-pair-probability-results-20261007.json)。
