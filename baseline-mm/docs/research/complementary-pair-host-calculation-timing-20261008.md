# 首折候选宿主计算代表测量（2026-10-08）

本次测量原公共策略输入装配与 `calculate` 的墙钟耗时。672个样本的 p50 为14.137402 ms、p95 为15.329496 ms、max 为18.055868 ms。结果只适用于下述硬件和构造负载，不是经营收益结果或正式生产时延。

对应 #185 的[准确分配](https://github.com/slowchillchill/btc-updown-marketmaker/issues/185#issuecomment-6053310439)。[机器结果](complementary-pair-host-calculation-timing-20261008.json)保存全部原始纳秒样本、各格与合并分布、冻结输入身份及实际决定。原始日志、构造账户诊断和编译记录保留在独立归档 `issue-185/host-timing-20261008`。

## 方法与负载

复用已有首折七份完整候选，不修改43个策略字段。公开事实由原 typed raw→DPT/Core→历史录制／public replay→SIM 公共消费构造。账户由原 SIM→NOE→Ledger／shared-run 形成；测试私有装配直接接收原 sealed rules 和原 finality，未使用旧测试快照或改费率的盈利夹具。

866个市场仅用作已知首折不同市场数量的代表规模。863个市场闭市且无账户责任，两个市场闭市且保留真实责任，一个市场当前可交易。每个独立2000 pUSD账户均保留相同两项闭市责任：第一个市场实际买入5份 Up，成交价0.55，未终局；第二个市场实际提交5份价格0.20的 GTC 挂单，尚未成交。二者覆盖单腿持仓与挂单，不覆盖已判定应收。

三种状态指当前市场：空仓、实际5份价格0.20的 GTC 挂单、实际买入5份的 Up 单腿。闭市责任在三种状态中都存在。因此“空仓”不表示整个账户无持仓。全部成交与责任通过原执行和经济事实读取断言；计时期间不分派计算所得意图，不改变账户，计时前后费用、现金与成交经济读取逐项保持一致。

当前市场接受301个不恒定的一秒 Chainlink spot 点，并逐点调用原 `calculate` 建立记忆。价格为 `65000 + (n % 11) - 5`，`n=1..301`；同时送入相同价格的 Binance aggTrade 和双方 Polymarket Book。全部实际依赖来源健康。首折七份候选的深度／成交压力权重均为零，不需要深度压力分支。300个相邻价对含273个绝对变化1美元和27个绝对变化10美元，跨度300秒；最终 sigma 必须等于 `sqrt((273 + 27*100)/300)`，验证原成熟记忆而非重复同一价格或初始化 sigma。

构造时钟从 `1787614800000` 起，位于原规则观察时刻 `1787614426333` 之后。历史点从起点后4秒到304秒，当前市场窗口为起点后300—600秒；最终测量截止为起点后304.002秒。构造时间不代表研究日期发生了变更，也未读取真实日期文件。

每格先完成上述装配与301次历史计算，再执行一次暖机和32次计时。计时从调用 `SharedExecutionV2::strategy_observation_input` 前开始，到 `StrategyInputV1::calculate` 返回完整输出为止，包含原公共组／账户读取、观察复制和策略计算。setup、历史回放、暖机、结果输出及返回对象析构不进入样本。重复计时保持同一公共截止与账户，策略自身按原规则更新记忆和请求编号；没有分派、账户推进或未来数据插入。

## 适用边界与后续时序

该负载只有一个当前市场，每本公开盘口各一个 bid／ask，两个闭市责任和成熟300秒记忆。它不测真实三日输入准备、全盘口宽度、所有账户对象规模、在线队列或最坏尾部上界。max 只是本次观察最大值，不替代 p50／p95，也不保证未来计算不超过它。测量期间未启动真实 prepare、经营账户比较或容量试验。

研究计划§5仍要求 p50／p95固定值与原 Sequence 敏感性。后续方案可明确使用本次相应固定值，并显式记录纳秒到宿主整数毫秒的映射及所选负载；本报告不正式采用参数。32个样本的每格序列及672个合并样本都是有限测量记录，不能自动循环、补齐或冒称三日 Sequence。完整三日 Sequence 的来源／覆盖和执行方案仍须准确说明，不能用 max 静默取代这项工作。

公开交付等待、计算开始等待和发送等待均未由本次计算区间测得。将它们显式设零仅为后续拟议研究假设，不是生产默认；原接收／准入事实及 SIM 代理／平台时延继续保留，不重复叠加或取消。实际经营作业仍按 #185 的实质授权执行。
