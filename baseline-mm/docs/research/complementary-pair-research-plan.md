## 3. 概率与跨源候选的形成

概率输入按正式结算规则逐市场连接正式阈值、参考类别及窗口，先统计合法状态的分母。Chainlink 现价形成因果历史与窗口积分近似；rolling TWAP只作该来源允许的未来水平参考，不被当成 spot路径积分。明确窗前可用临时参考、窗口历史不足、真实参考缺失、零方差及 NAV未知等不同状态。既有 D-0272 按实际动作依赖暂停，冻结诊断随相应计算保存，未来统计不能改写早先诊断。

初步比较滚动波动窗口15、30、60、120、300秒，属于探索窗口网格，不是行情陈旧门或固定交易周期。初始 sigma 来自较早拟合折的实际 spot平方变动／经过秒数，误差来自实际预测残差分布；不足时记录缺失与原候选行为，不用后折数据填补。终局概率按市场结果做 Brier、校准图和分层误差；若公开终局只支持二元结果，不能伪造连续价格误差。分析可在剩余300、240、180、120、60、30、10、1秒取样，标明仅是统计采样位置，不新增最后几秒禁开仓或强制策略 cadence。

[两市场窗口统计](complementary-pair-window-statistics-20260909-0000-0010.md)的原History要求价格对双端接收时间都在描述窗内；生产SignalMemory方差循环按右端纳入，可能包含跨左端一对。该区别未被规格§11规定为生产缺陷，原描述一致不能充当sigma验证。窗[1000,3000]ms及点(900,100)/(1500,101)/(2500,103)给出研究4/1秒与生产方差循环在其他前提满足时5/1.6秒的可复核关系；本段没有复制或修改生产估计器，也没有据此形成正式参数。

Binance 因果基差／创新在双方已接收且可见后计算，Chainlink 更新刷新基差，反转反复重算。比较无外部修正、创新修正和交易／深度压力修正；拟合较早折的有限系数，再在后折按距离、剩余时间和缺失状态检验。源时间领先但接收时已失效的信号不能计为可交易领先。盘口减量不是成交，公共成交方向不能代替自己的 Maker成交。重叠事件按一个市场机会段计数，日／市场块重采样呈现离散程度，不能假定每毫秒样本独立或用虚构统计门槛宣布成功。

输出为因果概率基线、跨源系数候选、来源资格与缺失分层、校准和反转证据。若短窗误差与假确定性系统增大、效果只存在于源时间、或者扣执行成本后无增益，应推翻或缩小对应候选，不擅自加 TTL、冷却或新的禁止条件。

## 4. 全部27个策略参数的形成与审定边界

当前 `ComplementaryPairConfigV1` 全部数值显式输入，没有正式数值默认。以下均为生成方法，实际值必须由后续结果填入；工程示例不提供正式数值。分组相邻字段共用说明但仍逐字段保存有效值及来源。

| 配置字段 | 候选形成方法／实际取舍 |
| --- | --- |
| `probability.volatility_window_ms` | 上述窗口网格按后折校准和可用性比较；短窗响应与噪声取舍 |
| `initial_sigma_usd_per_sqrt_second`、`estimation_error_usd` | 较早折波动／预测误差分布；保留初始不足与覆盖范围，非任意收益调参 |
| `binance_innovation_weight`、`binance_pressure_weight_usd`、`binance_trade_pressure_weight_usd` | 因果拟合及零修正消融；创新与压力分别识别，重叠信息不可重复贡献 |
| `quote.base_pair_shares` | 真实盘口可执行规模、资金周转及单侧后修复能力形成小集合；实际含费1000 pUSD投入与整批现金联合约束 |
| `base_half_spread`、`uncertainty_spread_weight`、`signal_spread_weight` | 实际价差、概率误差位置和信号变动分布形成候选；平台合法tick后重算成本 |
| `inventory_shift_per_pusd` | 不同未配对本金下真实逆向选择／修复与报价效果；取消库存偏移消融可推翻候选 |
| `joint_fill_scenario_weights` | 以原SIM真实自身成交的双腿、Up单腿、Down单腿、都不成交联合机会计数估计；没有下单的盘口触价不能估为本账户填单概率，不能两腿独立相乘；尾部按右删失单列 |
| `minimum_business_result_per_share` | 联合成交经营结果形成完整候选，含单腿后续成本与留孤腿；不是“配对盈利就必买”规则 |
| `execution_path_ms` | 实际路径测量／明确假设映射策略机会判断；不是宿主计算耗时，也不重复叠加SIM已有时延 |
| `repair.base_loss_allowance_per_share`、`time_loss_allowance_per_share`、`inventory_loss_allowance_per_share` | 等待／被动／FAK／留孤腿的增量代价和库存、时间分层形成有限小亏候选；正式风险数值须用户审定，不加账户累计修复亏损门 |
| `maximum_overfill_shares`、`maximum_overfill_pusd` | 原SIM金额BUY全域界及反向残余风险、现金锁资形成候选；不能拿最便宜盘口作最低成交价保证，不把合成 `Decimal::MAX` 当生产风险 |
| `maker_fill_weight`、`wait_price_improvement_per_share`、`residual_risk_weight` | 原自身Maker成交与等待改善、尾部风险的后折比较；分支自然未触发不宣称验证通过 |
| `maker_path_ms`、`active_path_ms` | 对应原路径测量及确定性敏感性，先撤／反馈／重算仍跨回调 |
| `enable_active_repair` | 比较被动修复消融与有限主动修复，显式 `false`，无热重载 |
| `risk.per_market_orphan_limit_pusd`、`account_orphan_limit_pusd` | 呈现实际孤腿本金、并发、修复现金与回撤的风险预算提案；不由样本盈利自动选定正式风险额度 |

报价参数先使用较早折实际价差／误差分布的四分位位置生成小集合，再按完整经营结果缩减；这是具体候选形成方法，不保证对应分位是最优或正式值。联合权重必须通过真实经营试验产生，不声称在尚未运行时已估得；第一批试验的联合权重作为显式机制候选，记录来源为假设，并以随后真实结果检验。

修复复用 `limit_buy_cost_v1` 与 `sim_market_buy_bounds_v1`，逐档贵价不得平均放行。全域份额界可能令常见参数没有可行 FAK，这是已认可能力边界；如实报告 Maker／等待／留孤腿，不放松规则凑分支。依 D-0274，公平溢价可以影响经营比较，不能成为额外独立否决门，也不能换名字藏进最高价或默认开关。利益／成本合格仍不要求成交。利润支持只占未反映公共损益的未决增量，按真实分派和迟到事实更新，不重复预算或改配平次序。

研究后的风险建议需给出每个实际数值、形成证据、资金占用／回撤／尾部的取舍和建议采用理由，再由用户裁决正式采用；本轮不提出未经数据支持的正式数字。2000 pUSD、逐市场含费1000 pUSD、高水位30%回撤等已定合同不重新问用户。

## 5. 时序测量与敏感性

宿主分别配置 `public_delivery_delay_ms`、`calculation_start_delay_ms`、`calculation_duration_ms`、`dispatch_delay_ms`，使用原 Fixed 或确定性 Sequence，不以本次回测机器墙钟决定收益。先按实际版本、硬件、负载和公开输入状态测量原策略计算及排队段，记录分布／样本量、暖机与并发条件；以测得 p50/p95固定值和原序列做敏感性。方案属于测量方法，当前没有实测生产时延值；显式零只作机制对照，不能当隐式默认。

公开源原可见时间和交付延迟分开，不能重复算已有接收事实；SIM自身代理／平台时延照原快照执行。策略三个路径参数只用于策略判断，和宿主真实开始、耗时、完成、调度发送逐项对应；冻结决定不得借计算期间新观察改价或回插过去。同毫秒可达请求和原完整隐藏桶沿原宿主推进。性能测量报告与经济结果分开，不把快机器收益当可部署收益。

正常 finality 固定为已核验项目假设，可在后续准确任务内用同一原类型预封定合法正常路径敏感性。失败敏感性选一个原合同允许的“经济已应用后 FAILED”代表性路径，按完整账户身份与 FILL ordinal 在运行前登记，不看结果后挑亏损或盈利成交；未触发要报告未触发。它验证原补偿与候选风险，不估计真实失败率。其他失败分支继续引用原组件代表性证据，不为研究复制领域全矩阵。

## 6. 连续账户比较与经济指标

研究内每个完整候选／消融使用独立运行账户，参数在相应检验折前固定。开发三天必须每候选一个2000 pUSD账户、一个Ledger、共享执行与策略实例连续跨所有市场。订单、预留、在途、孤腿、应收、费用和高水位保持，赎回确认前现金不增加。候选在开发开始前冻结；开发得分只支持开发选择，不反向改研究证据。
