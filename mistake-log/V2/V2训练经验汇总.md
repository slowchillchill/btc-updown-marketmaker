### E01. AlphaV2 signal gate 经验
- **experience_group：** `alpha_v2_signal_gate_lessons`
- **次数：** 3
- **分类：** 候选选择信号（`candidate_selection_signal`）
- **代表经验：** terminal gate 必须同时看 selected EV、baseline margin、side-match 与 no-test-rerank。；Stage B/export/paper 必须由 eligibility gate 授权，不能用局部正 EV 绕过。；control pass 用于 calibration，不是候选成功；无 family 默认可进 Phase 6A。
- **observed_result：** terminal selected-side EV 为负且低于 no-sort/best naive，但 AUC 仍为 0.8560。；8/8 Stage A runs exit 0，但 eligible_count=0。；16 primary rows中 8 个 signal pass、7 个 eligible；R6_C2_control pass 但不可导出。
- **interpretation：** 分类 AUC 不等于可交易 EV side-selection。；单日验证和多维 sweep 可能暴露局部信号，但不足以形成 robust roster。；pass_count、eligible_count 和 control role 必须分开解释。
- **not_error_reason：** 这是模型泛化/指标口径经验，不是 schema 或实现破坏。；gate 正确阻断后续阶段，这是训练筛选经验。；结果按预注册解释，属于候选筛选经验。
- **experience_ids：** `V2E0001,V2E0003,V2E0006`
- **证据：** REF012（poly-arb-ai/v2-docs/changelog/2026-05-14-phase5-1-terminal-gate.md L89-L107）；REF018（poly-arb-ai/v2-docs/changelog/2026-05-14-phase5-4-single-fold-repair.md L408-L443）；REF022（poly-arb-ai/v2-docs/changelog/2026-05-18-phase5-8-signal-gate-execution.md L127-L177）

### E02. paper 迁移经验

- **次数：** 3
- **分类：** paper 迁移经验（`paper_trade_transfer_learning`）
- **代表经验：** LIVE source of truth 用 JSONL，parquet 只做 post-run compact。；无 RAW run 不能用 B 路 replay-shadow 复盘异常，需在报告中标清。；报告脚本必须按 manifest/profiles 发现模型目录，不能硬编码单 profile。

- **interpretation：** 长跑先要可恢复和可读，再谈离线 parquet 分析。；endurance/stability 与 replay reproducibility 是不同目标。；迁移时要同时保护旧报告入口和新 profile comparison。
- **not_error_reason：** 这是用户确认的持久化取舍。；目标明确是稳定性验证，不是 replay gate。；兼容层是显式设计，不是重复实现。
- **experience_ids：** `V2E0016,V2E0017,V2E0018`

## 代表性负结果与保留价值
- AlphaV2 terminal gate、single-fold repair、full-history repair 的低分或弱信号，保留价值在于明确 selected EV、baseline margin、side-match、no-test-rerank 和 eligibility gate 的组合口径。
- Phase 6.5/6.6 的 replay 结果显示 leaderboard 可用于筛选，但 action-surface collapse 会让候选排名失去部署含义。
- Phase 6.7 的 failure-root 与 next-round gates 把 raw-output、threshold sweep、alpha sensitivity、control separation 固化为下一轮检查点。
- M5 纯 offline RL 负结果保留为训练经验，未来优先考虑 reward shaping、BC warm-start 或 counterfactual objective。

## replay / paper 迁移经验
- replay 只证明诊断面：independent replay、train-boundary leaderboard、top3 review 都不能绕过 action-surface audit 和 paper runtime gate。
- paper LIVE source of truth 使用 JSONL，parquet 是 post-run compact；无 RAW run 的异常复盘必须在报告中标明证据边界。
- 多 profile 报告必须依赖 manifest/profiles 发现模型目录，不能硬编码单 profile 或只看 reset 后最后一段 NAV。

## 不应计入错误的训练结果
- 没有实现缺陷证据的低分模型、弱候选、control pass、diagnostic-only leaderboard 和 replay 泛化不足，不计入错误。
- performance 低于预期本身不等于 bug；只有源证据明确指出错误假设、契约不一致、artifact 缺失、路径错误或流程遗漏时才转入错误台账。
- 训练经验仍要保留 run_id、candidate_id、train_boundary_id 和 truth_surface，避免未来重复试验时丢失负结果价值。
