- 构建：`cargo build -p backtest --example public_statistics_fixture --release --locked --offline -j 20`。
- 首次优化构建墙钟 83.382 秒；独审修正后重建墙钟 43.599 秒。先前二进制和原始结果均保留原身份。
- 最终程序 SHA-256：`d8f11bc5855dbfeaef5a552e6b7132a4adefe6f2e1be344eb007d0ad736f0f40`。
- 实际 CPU 配额 25 vCPU，内存配额 90 GiB。公共组和各账户在主线程按因果顺序消费，SIM 原后台记录线程并行。
  编译使用 20 作业；定向独立测试并行运行。没有 GPU 计算或 CPU/GPU 传输，显存不适用。

调用为 `<显式程序路径> <仓库外配置.json> <新输出目录>`。两个规模只改变同一配置的 `groups`，无需重新编译。
其余生效参数：消费者 2、进度每1000组、样本输出每1000组、公共交付延迟7ms，
