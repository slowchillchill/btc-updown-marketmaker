## 实际交付和业务边界

状态编码仍使用 fast596、slow433、六侧完整盘口、每帧一次 GRU；动作前缀改为 36。七个动作分图引用同一组新策略参数，在同一次冻结决定内复用规则及全部撤单对象编码，按当前阶段只调用需要的头。撤单仍遍历全人口，256 只是物理分块大小；归约顺序、f64 累加与并列规则保持。

价格头的最大宽度为 999。`price_indices` 是严格递增的 int64 原坐标 k−1，ONNX 实图先 Gather 权重与偏置再 Gemm；Python/Rust 消费者按相同合法区间分组，局部输出映回原坐标后选择。GTC 上界由公共精确费用核二分求得，FOK 沿原最低支出与本金规则。99/999 静态网格共享；实时现金、数量、费表和另一腿条件仍重新计算。

新 BUY 每腿只能选择普通 GTC 或 FOK。普通 GTC 显式 `post_only=false`，完成性、支持集、预留与意图装配一致；低于平台 mos 的数量仍可选择并消费真实拒单反馈。公共 GTD/FAK/PostOnly 订单表达和历史订单撤单保持。范围外真实 tick 明确终止受影响模型运行，保留原始值；不改写采集事实。

数量保持 q=n/100 和精确 BigUint 整数边界，固定 16 个分段号，不重编号非空段。唯一合法项在神经调用前直接推进、记录实际路径，不消耗 RNG，日志概率与熵贡献为零。完整联合熵另采独立完整动作，按§9.4的0.5系数报告 `−0.5×ell`，梯度代理为 `0.5×stop_gradient(ell+1)×ell`；所访问节点熵之和不作为联合熵。

双腿的 A→B 只发生在同一冻结决定内的条件解码。两腿参数全部确定后才产生单一 `SubmitPairedBuy` 并走既有批量提交；中间没有订单提交、账户变化、回执等待或 GRU 推进。

## 实际顺序、负载和剩余耗时

普通窗口每轮实际执行 64 次状态图，高更新窗口每轮 128 次：一组可包含多个原生帧，每帧一次 GRU 的时序未改变。新候选首组分别为小模型普通 109.749/118.041 ms、高更新 231.083/233.472 ms；大模型普通 128.427/128.532 ms、高更新 331.486/291.891 ms。全部首组保留在总体分布中；单独排除首组后的统计也仍高于目标。

两轮的动作计数完全相同。小模型高更新两版本均为 64 次 NoTrade；普通旧版为 64 次 NoTrade，新版先进行一次配对 FOK，再为 63 次 NoTrade，末尾本地待确认本金为 1000 pUSD。大模型旧版在两个窗口都进行 64 次配对 BUY；新版普通窗口为 41 次配对 BUY、19 次市场撤单、4 次 NoTrade，高更新为 19 次配对 BUY、45 次市场撤单。新版普通/高更新末尾本地待确认本金分别为 999.9529/999.9999 pUSD，旧版分别为 0.0120/0.116 pUSD；这些是仿真账本事实，不是收益结论。

在大模型旧版的每个窗口，每轮数量节点为 1472 次（64×23），另有动作族64次、变体128次、价格128次、PostOnly128次。新普通窗口数量节点97次，高更新57次；这同时包含16路分段和账户现金变化的影响。对于初始500万个整数的同一数量根区间，16路最多6次即可到达单一数量；完整数量可达性由小域穷举和精确边界测试另证。

新大模型普通窗口实际调用 family/objects 各64次、quantity97次、variant15次、price78次；价格语义步骤有82次，其中4次唯一项直接选择，其余有效价格数为2或3。高更新分别为64/64/57/15/34次，38个价格步骤中4个唯一项。两窗口的市场撤单均只有一个合法对象，未调用撤单评分图；路径照常记录。主矩阵的撤单人口始终为1，257对象/分块/梯度正确性由定向检查覆盖，不能据本矩阵声称大撤单人口性能已验证。

新大模型普通窗口的状态图均值为16.304—17.809 ms、原生输入7.807—8.067 ms、动作步骤13.480—13.782 ms；高更新分别为32.671—33.105、13.680—13.709、8.276—8.726 ms。第一轮普通窗口价格评分的单次 Session 运行均值为3.883 ms，费用特征0.031 ms、索引准备0.004 ms、ORT输入构造0.003 ms。当前配置下，原生输入、状态图和仍需执行的阶段图是主要剩余耗时；本次数据不支持“继续缩小价格数组即可达到完整服务4ms”的结论。

本矩阵的图加载成本增加：小模型约0.09→0.15秒，大模型约1.11—1.15→1.36—1.39秒。峰值RSS没有随参数减少同步下降：小模型普通约208→221 MiB、高更新约292—296→311—318 MiB，大模型均约2721—2729 MiB。没有把冷加载、首组、峰值内存或超过4ms的样本移出报告。
