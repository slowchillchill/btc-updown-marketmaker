## 实现与原责任

`PublicReplayV1`首次实际请求候选页时，创建属于该次有限重放的私有状态。其校验前沿复用原 `PublicRecordingReaderV1` 的解析、原序、身份、稳定分片计数和 EOF，绑定本次已恢复的稳定视图；打开时不预扫正文。原 `RunCursor` / `next_row`内部分出带物理位置的入口，原 schema 和读批次预算保持。

仅已验证的 `CanonicalEventRecordV2::ReferenceEvent`进入定宽索引，记录原输入位置、稳定分片、Parquet 行组、组内行和 TWAP 类型标记；保留非 TWAP 参考记录是为了维持原越界停止。候选正文按这些物理位置从原文件有界读取，同一次查询复用文件元数据与行组游标，不跨 Input 保存完整候选历史，也不复制选择或归约算法。

页满足行数上限后立即返回原 `finished=false`，不为证明 EOF 多读一条；首条截止之外的参考记录，无论是否 TWAP，都在游标过滤前结束该页。当前 Input 自身尚未由主游标排空的候选，仍可由独立原校验前沿读取。晚段 JSON 和分片计数错误只在原查询应访问的位置传播，错误层次与原分页入口对照。

公共 `PublicReplayV1` / `RecordedPublicGroupSourceV1` 外部接口保持。在线候选读取、保存依赖的完整 EOF 扫描及历史身份扫描沿原入口；没有改生产 writer、存储布局、选择规则、系统缓存设置或源数据。上述私有状态是本段工程选择，不另设业务准入合同。
