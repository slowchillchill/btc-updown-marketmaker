# Binance 深度组内共享及十二分钟重放成本对照

本报告交付 [#206](https://github.com/slowchillchill/btc-updown-marketmaker/issues/206)，为 #185 任务3提供公共依赖。`MarketBusinessObservationV1.binance_depth` 改为 `Arc<ObservedFactV1<BinanceDepthStateReferenceV1>>`：原 `close_group` 仍从唯一数量表投影一次完整深度，然后每个市场仅克隆同一个 Arc。每个后续组独立投影，不在 core 常驻第二份完整深度、不跨组复用，不改变全部已知市场的观察集合、事实、来源、时间、质量、依赖或错误前沿。

此次同配置串行基线、修改后各运行一次，均成功到正常 End/EOF。GNU 墙钟为415.53→276.82秒；`core.push` 为187.320409708→93.909526560秒，返回对象显式释放为68.568838427→29.198113536秒。两次分母及扫描计数保持。本次观察支持组内共享减少这两个已计量区间的成本；没有缓存清空、调度控制或重复试验，不把一次对照写成稳定加速比例。完整机器证据见[结果 JSON](binance-depth-shared-owner-12m.json)。
